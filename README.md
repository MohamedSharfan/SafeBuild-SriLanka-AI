AI-Powered Urban Risk & Illegal Construction Detection System for Sri Lanka

UrbanShield-AI-SriLanka is an intelligent geospatial monitoring system designed to detect illegal constructions and assess urban structural risks across Sri Lanka using Artificial Intelligence and satellite/geospatial data analysis.

The system leverages machine learning, image processing, and GIS data to identify unsafe building patterns, unauthorized constructions, and high-risk urban zones. It aims to support government authorities, urban planners, and disaster management teams in making data-driven decisions for safer city development.

Key Features:
AI-based illegal construction detection using satellite imagery
Urban risk zone classification (flood, landslide, structural risk areas)
Geospatial mapping and visualization dashboard
Automated alerts for high-risk areas
Scalable architecture for nationwide deployment in Sri Lanka


Tech Stack:
Python, TensorFlow / PyTorch, OpenCV, GeoPandas, QGIS, React, Node.js, PostgreSQL/PostGIS



Goal:
To build a smart, AI-driven urban monitoring system that improves safety, reduces illegal construction risks, and supports sustainable city planning in Sri Lanka.
